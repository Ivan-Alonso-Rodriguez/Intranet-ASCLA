# Historial de versiones

Este repositorio conserva commits y tags para las versiones del código fuente que pudieron verificarse a partir del historial Git original y de snapshots incluidos en el proyecto.

| Versión | Estado | Referencia |
|---|---|---|
| 1.0.3 | Historial Git original | `v1.0.3` |
| 1.0.4 | Historial Git original | `v1.0.4` |
| 1.1.0 | Historial Git original | `v1.1.0` |
| 1.2.0 | Historial Git original | `v1.2.0` |
| 1.3.0 | Snapshot recuperado | `v1.3.0` |
| 1.4.0 | Snapshot recuperado | `v1.4.0` |
| 1.4.1 | Snapshot recuperado | `v1.4.1` |
| 1.4.2 | Snapshot fuente no disponible en el archivo recibido | Sin tag |
| 1.5.0 | Snapshot recuperado | `v1.5.0` |
| 1.6.0 | Snapshot recuperado | `v1.6.0` |
| 1.7.0 | Estado final del historial recibido | `v1.7.0` |

La versión 1.4.2 aparece documentada y existe evidencia de hashes de sus archivos, pero su snapshot completo no estaba presente en el ZIP recibido ni en los objetos recuperables del repositorio. Por esa razón no se creó un tag `v1.4.2` con contenido aproximado o inventado. Si se recupera el ZIP original de esa versión, puede insertarse exactamente entre `v1.4.1` y `v1.5.0`.

La carpeta `docs/` se mantiene fuera del repositorio público y está excluida mediante `.gitignore`.
