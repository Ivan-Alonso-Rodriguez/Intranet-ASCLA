# Matriz de requisitos ASCLA

Fuente: DOCUMENTO DE ANALISIS Y DISEÑO ASCLA .pdf, 86 páginas. Revisión documental: 2026-10-08. Base: qa, 626197a, con cambios sin commit; plugin 1.10.7, esquema 14.

El texto de los 302 requisitos se conserva tal como estaba extraído; esta revisión actualiza estados, evidencias y notas. El [JSON](ascla-analysis.json) contiene los mismos registros que esta tabla.

**Código revisado** indica implementación inspeccionada y evidencia relacionada; no certifica aceptación integral. **Parcial** identifica una diferencia concreta; **Pendiente**, una función aún no implementada. **Validación pendiente** señala una comprobación no concluida. **Externo** necesita evidencia del despliegue. **Ajustado por decisión del usuario** registra una excepción expresa al PDF. **Fuera de alcance** conserva exclusiones del documento, aunque exista funcionalidad heredada.

Inventario: 62 reglas, 213 requisitos funcionales y 27 no funcionales. RF-214 está referenciado, pero no definido. RF-93 se normaliza a RF-093. Se conservaron las continuaciones de filas entre páginas y se separaron de las referencias a otras reglas.
